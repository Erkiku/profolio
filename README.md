# Abhishek Chaurasia - Portfolio

Static portfolio website built with HTML and CSS.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New Project** and import the repository.
3. Leave the framework preset as **Other** and leave the build command blank.
4. Click **Deploy**.

Vercel serves `index.html` from the project root and the portfolio itself from `portfolio.html`.
